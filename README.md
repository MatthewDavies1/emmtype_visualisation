# emmtype_visualisation
Process NRLBM internal database to visualise emmtype information over time. The script extracts emmcluster (e.g. A-C3, D1, E2) and emmtype (e.g. emm1, emm3) information, assigns isolates as originating from invasive, non-invasive or carriage sources and creates stacked barcharts for each.
Script to process and visualise just peurperal sepsis cases is also included but commented out.

Example data is available in metadata_example_input.xlsx
